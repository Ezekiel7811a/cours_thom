## Exercices

### [blockblast](blockblast/) — chasse aux bugs

Une version du jeu Block Blast en Python qui contient **8 bugs volontaires**.
Le but n'est pas d'écrire le jeu, mais de le réparer.

Commence par lire [blockblast/FICHE_ELEVE.md](blockblast/FICHE_ELEVE.md).

```bash
python blockblast/blockblast.py
```

```bash
python blockblast/tests_blockblast.py
```

Aucune installation nécessaire : le jeu utilise `tkinter`, qui est livré avec
Python.
